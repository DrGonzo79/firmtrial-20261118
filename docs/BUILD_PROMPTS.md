# Phased build prompts

1. **Evidence intake:** Add authenticated, tenant-isolated synthetic-case submissions with malware scanning, retention controls, immutable case versions, and explicit publication consent. Test authorization and upload failure paths.
2. **Reviewer console:** Implement double-blind criterion review, evidence citations, conflict disclosure, appeal workflow, and inter-rater reliability metrics. Published score must require qualified approval.
3. **Benchmark engine:** Add deterministic expected-result checks and model-assisted suggestions behind feature flags. Log model/prompt versions and reviewer overrides; never let a model publish.
4. **Public scorecards:** Generate signed, accessible, expiring snapshots with rubric version, evidence summaries, corrections, and paid-placement separation. Add monitoring for expired or withdrawn consent.
5. **Commercial test:** Add invoiced pilot slots and cohort analytics only after three manually paid assessments. Measure acquisition source, reviewer hours, gross margin, publication consent, and buyer-qualified actions.
